## 📌 Task 5 – RESTful API & CRUD Application

Task 5 focuses on integrating a **RESTful API with a front-end application**.

### Key Features

* RESTful API built using **Node.js and Express.js**
* CRUD operations:

  * `GET` – Retrieve tasks
  * `POST` – Create a new task
  * `PUT` – Update an existing task
  * `DELETE` – Delete a task
* Front-end interaction using JavaScript `fetch()`
* Dynamic task rendering
* Server-side input validation
* API error handling
* Responsive user interface
* REST API testing support

### API Endpoints

| Method | Endpoint         | Description              |
| ------ | ---------------- | ------------------------ |
| GET    | `/api/tasks`     | Retrieve all tasks       |
| GET    | `/api/tasks/:id` | Retrieve a specific task |
| POST   | `/api/tasks`     | Create a new task        |
| PUT    | `/api/tasks/:id` | Update a task            |
| DELETE | `/api/tasks/:id` | Delete a task            |
