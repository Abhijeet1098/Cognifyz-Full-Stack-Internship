## ▶️ How to Run

### Prerequisites

Make sure the following are installed on your system:

* **Node.js**
* **npm**
* **Git**
* **Visual Studio Code** or another code editor

You can verify Node.js and npm installation using:

```bash
node -v
npm -v
```

---

### Running a Task

Navigate to the required task directory.

For example, to run Task 1:

```bash
cd Task-1
```

Install the required dependencies:

```bash
npm install
```

Start the server:

```bash
node server.js
```

If the server starts successfully, open the displayed localhost URL in your browser.

For example:

```text
http://localhost:3000
```

Follow the same general process for Tasks 2–5. If a task uses a different port or startup command, use the configuration specified in that task's source code.
